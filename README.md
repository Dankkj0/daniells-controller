# daniells-controller

## v0.2.0 — DualSense Diagnostic

Painel de diagnóstico para testar como o Android interpreta um controle
DualSense.

### Testa em tempo real

- X
- Círculo
- Quadrado
- Triângulo
- L1 / R1
- L2 / R2
- L3 / R3
- Options / Share
- D-pad
- Eixos dos dois analógicos
- Intensidade dos gatilhos

### Objetivo

Descobrir exatamente quais códigos e eixos o Android fornece para o
DualSense antes de construir a ponte:

DualSense → celular → rede local → Android TV.

## Build

O APK de debug pode ser compilado pelo GitHub Actions.
